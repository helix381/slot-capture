# Slot Capture v0.3.0

正式工作台改为黑白灰、橙红重点与轻弥散背景；四个工作步骤独立分区，右侧保留规则助手。

## 使用流程

1. 在模拟器中打开目标机台，工作台选择已有档案，或新建档案。
2. 点击“自动检测并连接”，自动发现设备、前台游戏和心跳；技术信息在“连接详情”里查看或修正。多个候选才要求选择。
3. 规则可手填，也可拖入/粘贴截图后识图。核对名称、Symbol、玩法，勾选确认并保存；未确认的内容可作为草稿保存。
4. 新规则先“开始首转监听”，然后在游戏内手动转一次并完成奖励。尾链和最终审计通过后，正式采集入口可用。
5. 输入付费次数，点击“开始采集”，再手动开启游戏旋转。Bet从首个有效结果读取并锁定；免费次数另计。达到目标后停止新增付费，等待奖励收尾。

已经通过首转的规则档案，在当前连接通过后可直接采集。连接证明10分钟内有效；过期需重新检测。当前只有米亚适配器，其他机台可先建档。

## 数据和恢复

批次与原始数据仍保存在本地。旧版本档案库原位复用，不迁移或覆盖。删除仅把档案移入回收区，可撤销，历史采集和截图保留。工作台重开后恢复上次批次，也可通过右上角历史入口选择其他批次。

停止监听不等于停止游戏。关闭工作台后后台监听继续，重新打开可查看。正式看板不混入首转次数；返奖在最终审计前标为暂计值。

## 运行与验证边界

`dist/slot-capture-gui.exe`与`dist/slot-capture.exe`需放在一起。图形壳依赖Windows的.NET Framework与Edge WebView2 Runtime，Python及应用库已打包。CLI参数保持兼容；识图增加可选`--notes`，仍默认Luna / low。

自动回归使用临时数据、假设备和假的识图接口；页面交互使用无界面的独立Edge上下文。不自动打开工作台、不连接用户模拟器、不读真实剪贴板、不消耗识图额度。用户现场验收仍需覆盖WebView2壳启动、当前设备连接、一次真实首转及自动采集。
